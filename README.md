## 📖 About

Welcome to my **Bleep Academy – Artificial Intelligence with Agentic AI Internship Weekly Assignments** repository.

This repository documents my learning journey throughout the **Artificial Intelligence with Agentic AI Internship** at **Bleep Academy**. It contains weekly assignments, Python implementations, practical exercises, mini projects, quizzes, and capstone work completed during the internship.

The curriculum covers Python programming, data analytics, machine learning, deep learning, generative AI, Agentic AI, and real-world AI applications.
